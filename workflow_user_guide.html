🎬 DaVinci Resolve "Final Touch" Workflow (FCPXML Import)

Every pipeline run automatically compiles a standard Final Cut Pro XML (out/resolve_exports/<project>.fcpxml). This connects Remotion's programmatic graphics with DaVinci Resolve's Hollywood post-production suite:

  • 1-Click Timeline Import: Open DaVinci Resolve and go to File ➔ Import ➔ Timeline... (Import AAF, EDL, XML), then select your .fcpxml. Resolve will instantly populate the timeline with all tracks, video cuts, and audio.
  • Track V1 (Motion Background): Contains your high-resolution Remotion render (3D scenes, corporate slides, and kinetic graphics).
  • Track V2 (Pre-Sliced B-Roll & Facecam): Pre-cut into exact sentence intervals matching your voiceover. Simply drag and drop your talking-head camera clips or screen recordings onto the green markers on Track V2.
  • Track A1 & A2: Track A1 holds your studio clean voiceover; Track A2 holds ambient background music.
  • Color Grading with Tech_Cinematic.cube: In Resolve's Color Page, right-click the video node ➔ LUT ➔ Custom / Tech_Cinematic.cube (located in assets/grades/) for instant S-curve contrast, crisp cyan shadow push, and protected skin tones.
  • Fairlight Voice Mastering & Auto-Ducking:
    1. Voice EQ (Track A1): Enable 6-band parametric EQ, set high-pass filter at 80 Hz to cut rumble, and add a gentle 2.5 dB bell boost at 3.2 kHz for vocal clarity.
    2. Dynamics / Compressor (Track A1): Set ratio to 3:1, threshold at -18 dB, and attack to 15 ms. Turn on "Send" on Track A1 dynamics.
    3. Auto-Ducking (Track A2 BGM): Open Track A2 Dynamics, enable Compressor, and toggle "Listen" to Track A1. Whenever you speak, the background music will automatically duck by -14 dB!

What is Remotion's <Timeline /> Component?

The <Timeline /> package is Remotion's official commercial React UI component designed for web application developers building in-browser SaaS video editors (such as Canva, Descript, or CapCut Web). It provides React hooks and context providers (TimelineProvider, TimelineZoomProvider) to render a visual multi-track timeline inside a web browser with drag-and-drop layer reordering, item trimming, and real-time syncing to Remotion's <Player />.
